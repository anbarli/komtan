# Changelog

## 1.0.0

- Switched the extension UI, commands, starter content, and README to English.
- Updated Marketplace package metadata for the `ganbarli.komtan` extension identifier.
- Updated VSIX references for the `1.0.0` package.

## 0.6.2

- Added a duplicate content command for creating editable copies of existing records.
- Added duplicate title handling for copied records.
- Documented recommended demo screenshots for README and Marketplace.

## 0.6.1

- Refined Command Palette names for common actions.
- Improved empty library welcome actions.
- Added a filtered-empty tree state with a one-click clear filters action.

## 0.6.0

- Added Node test runner based unit tests for core helpers.
- Added `npm test` and `npm run pack` scripts.
- Added GitHub Actions CI workflow.
- Added publishing checklist documentation.

## 0.5.2

- Added sensitive content warning before saving values that look like tokens, API keys, passwords, private keys, JWTs, or connection strings.

## 0.5.1

- Fixed the favorite checkbox layout in the editor.
- Moved category, scope, and tags into one compact row.

## 0.5.0

- Added starter pack command with sample prompts, commands, templates, and references.
- Improved preview panel rendering for fenced code blocks and long text.
- Added Marketplace metadata fields to `package.json`.

## 0.4.0

- Added bulk operations for tags, categories, scopes, and deletion.

## 0.3.x

- Added filters by type, scope, and tag.
- Added preview panel.
- Added tag support.
- Added global/workspace scope support.
- Added import/export.
- Added quick Command Palette actions.
- Added template variables with `{{name}}` syntax.
- Added content types and smart category suggestions.

## 0.2.0

- Added prompt editing, favorites, category folders, search, and a multi-line editor.

## 0.1.0

- Initial prompt manager prototype.
